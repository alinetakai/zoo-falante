
# 🦁 Zoológico Falante

📌 **Explicação:**

Projeto autoral de um "Zoológico Falante", uma pequena simulação de um zoológico onde diferentes animais emitem sons. 

Usa herança e polimorfismo para organizar o código.


## Aprendizados

Herança e Polimorfismo.

🎯 **Objetivo:**

Mostrar que, mesmo chamando o mesmo método, os comportamentos mudam de acordo com a classe filha.


## Funcionalidades

🔧 **Regras:**

- Uma classe base chamada Animal com um método fazer_som().
- 3 classes filhas (ex: Leao, Galo, Elefante) e sobrescreva o método fazer_som() com sons diferentes.
- Uma lista de animais e use um laço de repetição para fazer todos eles emitirem som usando o mesmo comando: animal.fazer_som().

🎯 **Extra:**

- Versão gamificada com interface visual simples, usando a biblioteca tkinter e a pygame, que já vem com o Python. 

- O objetivo será clicar em botões de animais e ouvir seus sons representados como texto na tela.



## Stack utilizada

**Linguagem:** Python

**Bibliotecas:** tkinter e pygame


## Deploy

Para fazer o deploy desse projeto faça um clone do repositório e instale a biblioteca pygame no Python, caso ainda não a tenha instalado

```bash
  python.exe -m pip install pygame
```

Execute o jogo em seguida

```bash
  python.exe "[caminho-da-pasta-clonada]/zoo-com-sons.py"
```
